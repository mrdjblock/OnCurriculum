# Ontario Secondary Curriculum – website folder

This folder is the whole website. Upload everything in it (index.html, the data folder,
the docs folder and the originals folder) to a GitHub repository and turn on GitHub Pages.

- index.html  – the page
- data/       – course, subject and expectation data (replaces the Claude database)
- docs/       – one PDF per course
- originals/  – the complete original curriculum documents

To update a PDF later, replace the file in docs/ or originals/ using the same file name.
Curriculum text and PDFs are from the Ontario Ministry of Education. Not an official Ministry publication.
